# Repeater

A standalone Repeater example from the gallery.

Build `cmake --build build --target qamui_repeater_demo` and run
`./build/examples/components/repeater/qamui_repeater_demo`.
Press Q or Escape to quit.

The `repeater_smoke` Runner scenario checks the committed output.
See [Main.qml](Main.qml) for the complete application.
