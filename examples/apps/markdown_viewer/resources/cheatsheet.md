# Markdown Syntax & Formatting Cheatsheet

Quick reference for CommonMark and GitHub Flavored Markdown syntax.

## Headings

```markdown
# Heading Level 1
## Heading Level 2
### Heading Level 3
#### Heading Level 4
##### Heading Level 5
###### Heading Level 6
```

## Text Styles

- **Bold**: `**bold text**` or `__bold text__`
- *Italic*: `*italic text*` or `_italic text_`
- ~~Strikethrough~~: `~~strikethrough~~`
- `Inline Code`: `` `code span` ``

## Lists

### Unordered List
- First item
- Second item
  - Nested sub-item
  - Another nested item

### Ordered List
1. Step one
2. Step two
3. Step three

### Task List
- [x] Completed task
- [ ] Incomplete task
