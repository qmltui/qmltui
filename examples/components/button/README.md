# Button

A Qamui component example.

Build with `cmake --build build --target qamui_button_demo`.
Run `./build/examples/components/button/qamui_button_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R button --output-on-failure`.
