# Shortcut

A standalone Shortcut example from the gallery.

Build `cmake --build build --target qmltui_shortcut_demo` and run
`./build/examples/components/shortcut/qmltui_shortcut_demo`.
Press Q or Escape to quit.

The `shortcut_smoke` Runner scenario checks the committed output.
See [Main.qml](Main.qml) for the complete application.
