# Terminal View

A Qamui component example.

Build with `cmake --build build --target qamui_terminal_view_demo`.
Run `./build/examples/components/terminal_view/qamui_terminal_view_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R terminal_view --output-on-failure`.
