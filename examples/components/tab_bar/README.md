# Tab Bar

A QmlTui component example.

Build with `cmake --build build --target qmltui_tab_bar_demo`.
Run `./build/examples/components/tab_bar/qmltui_tab_bar_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R tab_bar --output-on-failure`.
