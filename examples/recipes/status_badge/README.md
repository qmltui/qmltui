# Status Badge

A QmlTui recipe example.

Build with `cmake --build build --target qmltui_status_badge_demo`.
Run `./build/examples/recipes/status_badge/qmltui_status_badge_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R status_badge --output-on-failure`.
