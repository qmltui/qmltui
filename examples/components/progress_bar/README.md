# Progress Bar

A Qamui component example.

Build with `cmake --build build --target qamui_progress_bar_demo`.
Run `./build/examples/components/progress_bar/qamui_progress_bar_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R progress_bar --output-on-failure`.
