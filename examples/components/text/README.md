# Text

A Qamui component example.

Build with `cmake --build build --target qamui_text_demo`.
Run `./build/examples/components/text/qamui_text_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R text --output-on-failure`.
