# Mouse Interaction

A QmlTui topic example.

Build with `cmake --build build --target qmltui_mouse_interaction_demo`.
Run `./build/examples/topics/mouse_interaction/qmltui_mouse_interaction_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R mouse_interaction --output-on-failure`.
