# Industrial PLC HMI Component Documentation

This directory contains developer reference documentation for the QML components comprising the **Industrial PLC HMI** example application.

## Component Index

- [HmiTheme](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/HmiTheme.md) — Singleton design system defining semantic colors, status palettes, and progress bar generators.
- [HeaderPanel](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/HeaderPanel.md) — Top status bar component displaying station ID and machine state badges.
- [NavTabBar](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/NavTabBar.md) — Function-key tab navigation bar with active tab highlights and alarm count alerts.
- [Gauge](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/Gauge.md) — Animated ASCII metric gauge with threshold warning and danger styling.
- [ActuatorLed](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/ActuatorLed.md) — Actuator/valve state indicator displaying active and inactive states.
- [ConfirmDialog](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/ConfirmDialog.md) — Floating modal popup dialog for confirming high-impact operator actions.
- [AlarmsView](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/AlarmsView.md) — Alarm log and fault history table view.
- [DiagnosticsView](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/DiagnosticsView.md) — Hardware diagnostics view displaying digital I/O states, power levels, and bus statistics.
- [SettingsView](file:///home/yosri/qamui/examples/industrial_plc_hmi/doc/SettingsView.md) — Parameter configuration view for adjusting motor speed and safety setpoints.
