# Table View

A Qamui component example.

Build with `cmake --build build --target qamui_table_view_demo`.
Run `./build/examples/components/table_view/qamui_table_view_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R table_view --output-on-failure`.
