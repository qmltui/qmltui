# Tool Tip

A Qamui component example.

Build with `cmake --build build --target qamui_tool_tip_demo`.
Run `./build/examples/components/tool_tip/qamui_tool_tip_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R tool_tip --output-on-failure`.
