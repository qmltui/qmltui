# Porting from QmlTui 0.4 to 0.5

QmlTui 0.5 unified the framework, QML modules, CMake targets, and runtime
environment variables under the `QmlTui` / `QMLTUI_*` name (including Runner's
`QMLTUI_RUNNER_*` variables and `qmltui.frames` logging category).

## Migrating from 0.4 to 0.5

| 0.4 API / Option | 0.5 Replacement |
| :--- | :--- |
| `TestRunner` (`qmltui::test_runner`, `QMLTUI_TEST_*`) | [`Runner`](../cpp-classes/runner.md) (`qmltui::runner`, `qmltui-runner`, `QMLTUI_RUNNER_*`) |
| `-DQMLTUI_ENABLE_BEHAVIOR=ON/OFF` | `-DQMLTUI_ENABLE_PRIVATE_QT=ON/OFF` (controls `Behavior` and private-Qt `PropertyChanges` binding restoration) |
| `TerminalHost` / `TerminalView` (`import QmlTui.TerminalView`) | [`PtyView`](https://github.com/qmltui/ptyview) (`import QmlTui.PtyView`, moved to the official `qmltui/ptyview` addon in 0.6) |
| `Terminal.FullScreen` | `Terminal.AltScreen` (with `Terminal.Inline` for normal-buffer CLI tools) |
| `Scrollback.write(text)` | [`Scrollback.print(text)`](../qml-types/scrollback.md) and `Scrollback.append(...)` |
| `Shortcut.sequence` integer bitmask only | [`Shortcut.sequence`](../qml-types/shortcut.md) accepts both key-chord strings (`"Ctrl+Q"`, `"F5"`) and Qt bitmasks |
| `Animation` finite loop counts only | [`Animation.Infinite`](../qml-types/animation.md) (`-1`) for continuous animations |
| `Palette`, `Switch`, `Toast` in `QmlTui.Controls` | Per-item color properties (`color`, `textColor`, `borderColor`) and recipes under `examples/recipes/` |

## Highlights in 0.5

- Gallery demos moved under `examples/gallery/` and copyable standalone recipes under `examples/recipes/` (`qmltui_<directory>_demo`), while full showcase applications moved to `qmltui/apps`.
- Reference documentation reorganized into Getting Started, Guides, QML Types, C++ Classes, Examples, and Changes.
- `Runner` added committed-scrollback assertions, deterministic virtual-clock stepping, extended `expectStyle()` attribute checks, and Asciinema v2 `.cast` recording.
