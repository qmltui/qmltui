# Image

A QmlTui component example.

Build with `cmake --build build --target qmltui_image_demo`.
Run `./build/examples/components/image/qmltui_image_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R image --output-on-failure`.
