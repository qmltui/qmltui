# Animation

A QmlTui topic example.

Build with `cmake --build build --target qmltui_animation_demo`.
Run `./build/examples/topics/animation/qmltui_animation_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R animation --output-on-failure`.
