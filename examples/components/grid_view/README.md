# GridView

A standalone GridView example from the gallery.

Build `cmake --build build --target qmltui_grid_view_demo` and run
`./build/examples/components/grid_view/qmltui_grid_view_demo`.
Press Q or Escape to quit.

The `grid_view_smoke` Runner scenario checks the committed output.
See [Main.qml](Main.qml) for the complete application.
