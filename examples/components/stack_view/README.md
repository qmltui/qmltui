# StackView

A standalone StackView example from the gallery.

Build `cmake --build build --target qmltui_stack_view_demo` and run
`./build/examples/components/stack_view/qmltui_stack_view_demo`.
Press Q or Escape to quit.

The `stack_view_smoke` Runner scenario checks the committed output.
See [Main.qml](Main.qml) for the complete application.
