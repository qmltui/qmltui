# Color Type Resolution

A Qamui topic example.

Build with `cmake --build build --target qamui_color_type_resolution_demo`.
Run `./build/examples/topics/color_type_resolution/qamui_color_type_resolution_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R color_type_resolution --output-on-failure`.
