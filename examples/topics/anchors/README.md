# Anchors

A Qamui topic example.

Build with `cmake --build build --target qamui_anchors_demo`.
Run `./build/examples/topics/anchors/qamui_anchors_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R anchors --output-on-failure`.
