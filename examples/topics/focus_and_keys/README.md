# Focus And Keys

A Qamui topic example.

Build with `cmake --build build --target qamui_focus_and_keys_demo`.
Run `./build/examples/topics/focus_and_keys/qamui_focus_and_keys_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R focus_and_keys --output-on-failure`.
