# Big Text

A Qamui component example.

Build with `cmake --build build --target qamui_big_text_demo`.
Run `./build/examples/components/big_text/qamui_big_text_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R big_text --output-on-failure`.
