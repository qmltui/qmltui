# Sparkline

A QmlTui component example.

Build with `cmake --build build --target qmltui_sparkline_demo`.
Run `./build/examples/components/sparkline/qmltui_sparkline_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R sparkline --output-on-failure`.
