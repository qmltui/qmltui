# Lazy Model

A QmlTui topic example.

Build with `cmake --build build --target qmltui_lazy_model_demo`.
Run `./build/examples/topics/lazy_model/qmltui_lazy_model_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R lazy_model --output-on-failure`.
