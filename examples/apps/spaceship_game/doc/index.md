# Spaceship Game Component Documentation

This directory contains developer reference documentation for the QML component delegates comprising the **Spaceship Game** terminal arcade example.

## Component Index

- [Bullet](file:///home/yosri/qtui/examples/spaceship_game/doc/Bullet.md) — Player projectile entity delegate (`^`).
- [Enemy](file:///home/yosri/qtui/examples/spaceship_game/doc/Enemy.md) — Enemy ship entity delegate with 3 enemy type classes (`v`, `<M>`, `oXo`).
- [Explosion](file:///home/yosri/qtui/examples/spaceship_game/doc/Explosion.md) — Multi-frame particle animation effect (`*`, `#`, `+`, `.`).
- [PowerUp](file:///home/yosri/qtui/examples/spaceship_game/doc/PowerUp.md) — Collectible item delegate (`[S]`, `[F]`, `[H]`).
- [Star](file:///home/yosri/qtui/examples/spaceship_game/doc/Star.md) — Parallax starfield background particle delegate (`.`, `+`, `*`).
