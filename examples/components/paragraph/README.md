# Paragraph

A Qamui component example.

Build with `cmake --build build --target qamui_paragraph_demo`.
Run `./build/examples/components/paragraph/qamui_paragraph_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R paragraph --output-on-failure`.
