# Busy Indicator

A Qamui component example.

Build with `cmake --build build --target qamui_busy_indicator_demo`.
Run `./build/examples/components/busy_indicator/qamui_busy_indicator_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R busy_indicator --output-on-failure`.
