# Text Input

A Qamui component example.

Build with `cmake --build build --target qamui_text_input_demo`.
Run `./build/examples/components/text_input/qamui_text_input_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R text_input --output-on-failure`.
