# Check Box

A Qamui component example.

Build with `cmake --build build --target qamui_check_box_demo`.
Run `./build/examples/components/check_box/qamui_check_box_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R check_box --output-on-failure`.
