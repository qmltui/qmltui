# Branding Proposals: Qami vs Qamui

This directory contains visual and text branding explorations for renaming the project from **Qtui** to either **Qami** or **Qamui**.

---

## 🌟 The "Rocket" Cyber-Fox / Raccoon Mascot

Inspired by the scrappy, brilliant tinkerer persona (reminiscent of Rocket Raccoon), with folded origami armor plates and signature terminal prompt eyes: **`>`** (command prompt) and **`_`** (blinking cursor).

| Tweaked / Refined Concept | Simplified Flat Sticker | Terminal Green Edition |
| :---: | :---: | :---: |
| ![Rocket Tweaked](./qami-rocket-tweaked.jpg) | ![Rocket Simplified](./qami-rocket-simple.jpg) | ![Fox Terminal](./qami-fox-terminal.jpg) |

## 💻 Terminal / ASCII Text Equivalents
