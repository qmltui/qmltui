## Logo system (2026-09-28)

Hand-authored vector logo, generated by [`qamui_logo.py`](./qamui_logo.py) (stdlib Python, no
dependencies). Regenerate with `python3 docs/assets/branding/qamui_logo.py docs/assets/branding`.
Preview of every asset at 200, 96, 48, 32 and 16 px on dark and light: [`qamui_logo_sheet.png`](./qamui_logo_sheet.png).

**Concept.** The mark is a **Q made of two glyphs**: an **O** and a **`>` prompt**. The chevron
stays upright so it keeps reading as a prompt, and its upper arm crosses the ring to become the
Q's tail, the way classic grotesque Qs cross the bowl. Ring and chevron share one stroke weight, so
in a single colour the shape is simply a Q; in colour the tail lights up as the prompt. The
wordmark is a geometric monoline on the same stroke, the mark stands as its Q, and the `i` carries
a block cursor as its tittle.

| file | use |
| --- | --- |
| `qamui_mark.svg` | primary mark for dark backgrounds (paper-white ring, green chevron) |
| `qamui_mark_light.svg` | same for light backgrounds (ink ring, darker green) |
| `qamui_mark_mono.svg` | one-colour Q in `currentColor`; favicons, docs sidebars, stamps |
| `qamui_mark_tile.svg` | mark on a rounded navy tile, for app icons and avatars |
| `qamui_lockup_dark.svg` / `qamui_lockup_light.svg` | "Qamui" wordmark with the mark as the Q; default for README headers and the website |
| `qamui_mark_cells.txt` | the mark as ANSI half-blocks (24x12, 16x8, 10x5) and braille (20x10, 12x6) for banners and an in-library demo; `qamui_mark_cells.png` shows how it renders |

**Palette.**

| role | dark bg | light bg |
| --- | --- | --- |
| ring, letters | `#F6F7F9` | `#1A1D26` |
| accent (chevron, cursor tittle) | `#00FF66` | `#00A651` |
| tile / page | `#0B1020` | `#F6F7F9` |

**Rules.** Keep the 90 degree opening and the upright chevron; a rotated chevron reads as a
checkmark and a chevron hanging off the ring reads as a magnifying glass. Do not add a cursor or
anything else inside the O. The accent is CRT phosphor green and is deliberately brighter and
cooler than Qt's `#41CD52`; do not drift toward Qt green. It is a single constant in the script.

Rejected on 2026-09-28: an origami raccoon head with a ringed Q tail (too illustrative), a ring
opened at the bottom right with the chevron folded out (reads as a map pin or speech bubble).
