# Canvas

A QmlTui component example.

Build with `cmake --build build --target qmltui_canvas_demo`.
Run `./build/examples/components/canvas/qmltui_canvas_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R canvas --output-on-failure`.
