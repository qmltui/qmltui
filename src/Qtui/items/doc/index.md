# Qtui Items Module C++ Documentation

This directory contains developer reference documentation for visual UI items in **Qtui**.

## Class Index

- [Item](file:///home/yosri/qtui/Tui/src/items/doc/Item.md) — Base visual element class providing spatial positioning, focus, anchoring, and event handlers.
- [Rectangle](file:///home/yosri/qtui/Tui/src/items/doc/Rectangle.md) — Visual item rendering background fills and terminal border styles.
- [Text](file:///home/yosri/qtui/Tui/src/items/doc/Text.md) — Visual text rendering component supporting rich text, ANSI codes, and alignment.
- [MouseArea](file:///home/yosri/qtui/Tui/src/items/doc/MouseArea.md) — Invisible input element capturing terminal mouse clicks and hover coordinates.
- [Loader](Loader.md) — Dynamically creates a QtUI item from an inline component or URL.
