# Scroll View

A QmlTui component example.

Build with `cmake --build build --target qmltui_scroll_view_demo`.
Run `./build/examples/components/scroll_view/qmltui_scroll_view_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R scroll_view --output-on-failure`.
