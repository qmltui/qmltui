# Standard Item Delegate

A QmlTui component example.

Build with `cmake --build build --target qmltui_standard_item_delegate_demo`.
Run `./build/examples/components/standard_item_delegate/qmltui_standard_item_delegate_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R standard_item_delegate --output-on-failure`.
