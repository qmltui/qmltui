# Layouts

A QmlTui topic example.

Build with `cmake --build build --target qmltui_layouts_demo`.
Run `./build/examples/topics/layouts/qmltui_layouts_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R layouts --output-on-failure`.
