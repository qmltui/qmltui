# Text Area

A QmlTui component example.

Build with `cmake --build build --target qmltui_text_area_demo`.
Run `./build/examples/components/text_area/qmltui_text_area_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R text_area --output-on-failure`.
