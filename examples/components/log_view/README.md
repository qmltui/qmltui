# LogView

A standalone LogView example from the gallery.

Build `cmake --build build --target qmltui_log_view_demo` and run
`./build/examples/components/log_view/qmltui_log_view_demo`.
Press Q or Escape to quit.

The `log_view_smoke` Runner scenario checks the committed output.
See [Main.qml](Main.qml) for the complete application.
