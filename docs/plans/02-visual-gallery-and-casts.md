# Plan 02: Visual Gallery, Component Catalog, and Asciinema Casts

## 1. Goal

Make Qtui visual before it is textual. Every app and every component gets a
moving or still preview that loads instantly, is copyable as text, and is
generated by a script so it never goes stale.

This plan merges the former "gallery" and "Tier 1 casts" plans. The WebAssembly
playground is Plan 05 and is not a launch dependency.

## 3. One Recording Pipeline Feeds Everything

Do not maintain separate PNG, GIF, and cast pipelines. Record one `.cast` per
app and per component with a scripted, deterministic session, then derive
stills from it.

### Recording (`scripts/record_casts.sh`)

Each app already has `TestRunner` scenarios (`test_*.js`). A recording is the
same scenario replayed with live ANSI output inside a fixed-size pty:

```bash
#!/usr/bin/env bash
set -euo pipefail
OUT="website/static/casts"
mkdir -p "$OUT"

record() {  # name  binary  scenario.js  cols  rows
    local name=$1 bin=$2 script=$3 cols=${4:-100} rows=${5:-30}
    asciinema rec --overwrite --cols "$cols" --rows "$rows" \
        --command "env QTUI_TEST_LIVE=1 QTUI_SCRIPT=$script $bin" \
        "$OUT/$name.cast"
}

record industrial_plc_hmi  ./build/examples/apps/industrial_plc_hmi/qtui_industrial_plc_hmi examples/apps/industrial_plc_hmi/test_plc.js
record btop                ./build/examples/apps/btop/qtui_btop                        examples/apps/btop/test_btop.js
record markdown_viewer     ./build/examples/apps/markdown_viewer/qtui_markdown_viewer  examples/apps/markdown_viewer/test_markdown_viewer.js
record file_manager        ./build/examples/apps/file_manager/qtui_file_manager        examples/apps/file_manager/test_navigation.js
record plotting_dashboard  ./build/examples/apps/plotting_dashboard/qtui_plotting_dashboard examples/apps/plotting_dashboard/test_plotting.js
record pos_cashier         ./build/examples/apps/pos_cashier/qtui_pos_cashier          examples/apps/pos_cashier/test_pos.js
record snake_game          ./build/examples/apps/snake_game/qtui_snake_game            examples/apps/snake_game/test_snake_ai.js
record twozero48           ./build/examples/apps/twozero48/qtui_twozero48              examples/apps/twozero48/test_twozero48.js
```

`QTUI_TEST_LIVE=1` makes the TestRunner emit real ANSI frames instead of quiet
commits, which is what the recorder needs. Component recordings use a short
`docs_<component>.js` scenario that exercises focus, a keypress, and a value
change over roughly six seconds.

### Stills

- Animated preview for README and social cards: `agg <name>.cast <name>.gif`.
- Still SVG for component cards: `svg-term --in <name>.cast --at 3000 --out <name>.svg`.
  SVG keeps text selectable, scales cleanly, and is a few kilobytes.

`QTUI_CAPTURE_AFTER_MS` writes `capture.txt` and `capture_styled.txt` only. `TestRunner` has no image capture
(it was removed together with its Qt Gui dependency), which is why stills
derive from casts.

### Size budget

Measure, do not assume. The `.cast` files are small, but the `asciinema-player`
bundle is several hundred kilobytes. Load it lazily on scroll into view and
report actual sizes in the PR. Only publish numbers on the site that came from
`pnpm build` output.

### `AsciinemaPlayer.svelte`

```svelte
<script lang="ts">
  import TerminalWindow from './TerminalWindow.svelte';
  let { src, title = 'preview', cols = 100, rows = 30, poster = 'npt:3' } = $props();
  let container: HTMLDivElement;

  $effect(() => {
    let player: { dispose(): void } | undefined;
    const io = new IntersectionObserver(async ([entry]) => {
      if (!entry.isIntersecting || player) return;
      const { create } = await import('asciinema-player');
      player = create(src, container, { cols, rows, poster, loop: true, autoPlay: true, fit: 'width', theme: 'qtui' });
    });
    io.observe(container);
    return () => { io.disconnect(); player?.dispose(); };
  });
</script>

<TerminalWindow {title}>
  <div bind:this={container}></div>
</TerminalWindow>
```

`theme: 'qtui'` is a custom player theme in `app.css` using the brand palette.
`poster: 'npt:3'` shows a real frame before autoplay so nothing is blank.

Still SVG, type name, one-line summary from frontmatter, category chip, and a
link to the reference page. The catalog grid filters by category and by
