# Ansi Styling

A QmlTui topic example.

Build with `cmake --build build --target qmltui_ansi_styling_demo`.
Run `./build/examples/topics/ansi_styling/qmltui_ansi_styling_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R ansi_styling --output-on-failure`.
