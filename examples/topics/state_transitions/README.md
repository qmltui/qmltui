# State Transitions

A QmlTui topic example.

Build with `cmake --build build --target qmltui_state_transitions_demo`.
Run `./build/examples/topics/state_transitions/qmltui_state_transitions_demo`.
See [main.cpp](main.cpp) for startup and local QML files for the interface.

The example is included when its optional modules are enabled.
Run its scenario with `ctest --test-dir build -R state_transitions --output-on-failure`.
